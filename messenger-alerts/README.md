# התראות מסנג׳ר לוואטסאפ

כשמישהו כותב לדף העסקי של לקוח במסנג׳ר, הלקוח מקבל התראה לוואטסאפ הרגיל שלו:

> 📩 הודעה חדשה בעמוד **פיצה של משה**
> מאת: יוסי כהן
> "היי, יש לכם מקום ביום חמישי?"
> **[לתשובה במסנג׳ר]**

הכפתור פותח את תיבת ההודעות של הדף ב־Meta Business Suite.

- **התראה אחת לשיחה:** מי שכותב כמה הודעות ברצף מייצר התראה אחת, ולא אחת לכל הודעה. התראה נוספת על אותה שיחה יוצאת רק אחרי 10 דקות.
- **עלות:** כ־2 אגורות להתראה, לפי התעריף של מטא לישראל. אם הלקוח כתב למספר של המערכת ב־24 השעות האחרונות, ההתראה חינמית.
- **שרת:** רץ בחינם ב־Cloudflare, באותו פרויקט של "לו״ז יומי", בנתיב `/m`.

## איך זה בנוי

| כתובת | מה יש שם |
|---|---|
| `/m/admin` | עמוד הניהול: הגדרות, חיבור דפים, בדיקות ויומן |
| `/m/webhook` | הכתובת שמטא קוראת לה על כל הודעה חדשה |
| `/m/privacy` | מדיניות פרטיות, שמטא דורשת |

## הקמה

### שלב 0: סיסמה לעמוד הניהול (ב־Cloudflare)
1. בפרויקט `psychic-fishstick` נכנסים ל־**Settings**, ואז **Variables and Secrets**.
2. לוחצים **Add**, בוחרים סוג **Secret**, ובשם כותבים `ADMIN_PASSWORD`.
3. בשדה הערך כותבים סיסמה חזקה, ולוחצים **Deploy**.

### שלב 1: אפליקציה ב־Meta for Developers
1. נכנסים ל־[developers.facebook.com/apps](https://developers.facebook.com/apps) ויוצרים אפליקציה חדשה מסוג Business.
2. מוסיפים לה שני מוצרים: **Messenger** ו־**WhatsApp**.
3. ב־**App settings ← Basic** מעתיקים את ה־**App ID** ואת ה־**App Secret**.

### שלב 2: וואטסאפ
1. ב־**WhatsApp ← API Setup** מוסיפים את המספר הייעודי ומאמתים אותו ב־SMS. המספר לא יכול להיות מחובר לאפליקציית וואטסאפ רגילה.
2. מעתיקים את ה־**Phone number ID** ואת ה־**WhatsApp Business Account ID**.
3. ב־WhatsApp Manager מוסיפים אמצעי תשלום.
4. **טוקן קבוע:** ב־Business Settings פותחים **System users** ומוסיפים משתמש מסוג Admin. משייכים לו את האפליקציה ואת חשבון הוואטסאפ, ומפיקים טוקן עם ההרשאות `whatsapp_business_messaging` ו־`whatsapp_business_management`.

### שלב 3: עמוד הניהול
1. פותחים את `https://<הכתובת שלך>/m/admin` ונכנסים עם הסיסמה משלב 0.
2. ממלאים את כל השדות בחלק 1, ולוחצים **שמירה**.

### שלב 4: Webhooks
בחלק 2 של עמוד הניהול מופיעים **Callback URL** ו־**Verify token**. מדביקים אותם בשני מקומות באפליקציה במטא:
- **Messenger ← Webhooks:** מסמנים את השדה `messages`.
- **WhatsApp ← Configuration ← Webhook:** מסמנים את השדה `messages`. דרכו המערכת יודעת כשהתראה לא נמסרה.

### שלב 5: תבנית ההודעה
בחלק 3 של עמוד הניהול לוחצים **שליחת התבנית לאישור**. אחר כך לוחצים **בדיקת מצב** עד שמופיע "מאושרת".

### שלב 6: חיבור דפים
1. ב־[Graph API Explorer](https://developers.facebook.com/tools/explorer) בוחרים את האפליקציה ובוחרים **User Token**.
2. מסמנים את ההרשאות `pages_show_list`, `pages_messaging`, `pages_manage_metadata` ו־`pages_read_engagement`, ולוחצים **Generate Access Token**.
3. מעתיקים את הטוקן ומדביקים אותו בחלק 4 בעמוד הניהול, ואז לוחצים **טעינת הדפים שלי**.
4. ליד כל דף כותבים את מספר הוואטסאפ של הלקוח, לוחצים **חיבור הדף** ואז **שליחת בדיקה**.

הטוקנים של הדפים לא פגים, ולכן אין צורך לחזור על החיבור.

### שלב 7: אישור מטא (App Review)
עד שמטא מאשרת את האפליקציה, ההתראות יוצאות רק על הודעות שנשלחות על ידי אנשים עם תפקיד באפליקציה, כמוך. זה מספיק כדי לבדוק שהכול עובד. כדי לקבל התראות על הודעות של לקוחות אמיתיים:
1. **אימות עסק (Business Verification)** ב־Business Settings.
2. **Advanced Access** להרשאה `pages_messaging` דרך App Review, כולל סרטון קצר שמראה איך המערכת עובדת. בטופס מדביקים את כתובת מדיניות הפרטיות מחלק 2 בעמוד הניהול.
3. אחרי האישור מעבירים את האפליקציה למצב **Live**.

## בדיקה מקומית

```bash
cd luz-yomi && npm install && cd ..
./luz-yomi/node_modules/.bin/wrangler dev --var ADMIN_PASSWORD:test --var GRAPH_BASE:http://127.0.0.1:9998
```

כדי לבדוק בלי לשלוח בקשות אמיתיות למטא, `GRAPH_BASE` מפנה את כל הקריאות ל־Graph API לשרת דמה מקומי.
