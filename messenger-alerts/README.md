# התראות מהעמודים: הודעה חדשה במסנג׳ר קופצת ללקוח על המסך הנעול

כשמישהו כותב לדף העסקי של לקוח במסנג׳ר, הלקוח מקבל תוך דקה התראה על הטלפון:

> 📩 **פיצה של משה**
> יוסי כהן: היי, יש לכם מקום ביום חמישי?

לחיצה על ההתראה פותחת את תיבת ההודעות של הדף. בלי אפליקציה מחנות, בלי וואטסאפ ובלי תשלום.

## איך זה עובד, ולמה זה עוקף את האישור של מטא

- במקום לבקש ממטא *לשלוח* כל הודעה (Webhook, שדורש App Review), המערכת **קוראת** את תיבת ההודעות של כל דף אחת לדקה, עם טוקן של מנהלת הדפים. לקריאה כזאת לא צריך אישור.
- כל לקוח מקבל קישור אישי. הוא מוסיף אותו למסך הבית פעם אחת ומאשר התראות, כמו באפליקציית "לו״ז יומי". ההתראות מגיעות דרך Web Push, גם כשהטלפון נעול.
- התראה אחת לכל שיחה: מי שכותב כמה הודעות ברצף מייצר התראה אחת. התראה נוספת על אותה שיחה יוצאת רק אחרי 10 דקות.
- הכול רץ בפרויקט `psychic-fishstick` ב־Cloudflare, בנתיב `/m`. אין פרויקט חדש להקים.

| כתובת | מה יש שם |
|---|---|
| `/m` | עמוד הניהול: מוביל שלב אחר שלב, בעברית |
| `/m/c/<דף>/<קוד>/` | האפליקציה של הלקוח: הפעלת התראות ורשימת הפניות האחרונות |
| `/m/privacy` | מדיניות פרטיות |

## הקמה

הכול מתוך עמוד הניהול, שמסביר כל שלב על המסך. בקצרה:

1. **סיסמה:** בכניסה הראשונה ל־`/m` בוחרים סיסמה.
2. **אפליקציה במטא (3 דקות, פעם אחת):** ב־[Meta for Developers](https://developers.facebook.com/apps) יוצרים אפליקציה מסוג Business, ומעתיקים את ה־App ID וה־App Secret לעמוד הניהול. לא מוסיפים מוצרים, Webhooks או אישורים.
3. **חיבור הדפים:** ב־[Graph API Explorer](https://developers.facebook.com/tools/explorer/) בוחרים את האפליקציה, מבקשים את ההרשאות `pages_show_list`, `pages_messaging`, `pages_manage_metadata`, `pages_read_engagement`, לוחצים Generate Access Token ומדביקים את הטוקן בעמוד הניהול. המערכת ממירה אותו לטוקן קבוע ומציגה את כל הדפים. ליד כל דף לוחצים "חיבור".
4. **התקנה אצל הלקוח:** ליד כל דף יש כפתור "העתקת הודעה ללקוח". שולחים לו אותה בוואטסאפ: הוא פותח את הקישור, מוסיף למסך הבית ולוחץ "הפעלת התראות".
5. **בדיקה:** "שליחת בדיקה" ליד הדף, ואז הודעה אמיתית במסנג׳ר.

## כדאי לדעת

- **אייפון:** צריך iOS 16.4 ומעלה, ולפתוח את האפליקציה מהאייקון במסך הבית. באנדרואיד מספיק כרום.
- **אם הגישה לדף פגה** (למשל אחרי שינוי סיסמה בפייסבוק), עמוד הניהול מסמן את הדף באדום. מדביקים טוקן חדש בשלב 2 ולוחצים "טעינת הדפים", והדף מתחבר מחדש לבד.
- **מה נשמר בשרת:** שם הדף, הטוקן שלו, המכשירים שחוברו, 30 הפניות האחרונות (שם, תחילת ההודעה, שעה) ויומן קצר. תוכן מלא של שיחות לא נשמר.
- **מגבלות של מטא:** כל דף נקרא 1,440 פעמים ביום. אם מטא מבקשת להאט, המערכת ממתינה 5 דקות וממשיכה.

## בדיקה מקומית

```bash
cd luz-yomi && npm install && cd ..
./luz-yomi/node_modules/.bin/wrangler dev --var GRAPH_BASE:http://127.0.0.1:9998 --var ALLOW_HTTP_PUSH:1
```

`GRAPH_BASE` מפנה את הקריאות ל־Graph API לשרת דמה מקומי, ו־`ALLOW_HTTP_PUSH` מאפשר מינוי התראות לשרת בדיקה ב־http.

## למפתחים

- `src/index.js` – הניתוב תחת `/m`, ו־Durable Object אחד (`AlertsHub`) שמחזיק את ההגדרות והדפים, קורא את תיבות ההודעות עם alarm כל דקה ושולח Web Push.
- `src/meta.js` – קריאות ל־Graph API: המרת טוקן, רשימת דפים וקריאת שיחות.
- `src/client.js` – עמוד הלקוח, ה־manifest וה־service worker שלו.
- `src/admin.js` – עמוד הניהול המודרך.
- ההצפנה של Web Push משותפת עם "לו״ז יומי": `luz-yomi/src/webpush.js`.
