# לו״ז יומי: אפליקציה לאייפון עם תזכורות במסך נעול

זו גרסה של "לו״ז יומי" שמתקינים במסך הבית של האייפון. התזכורות מגיעות כהתראה רגילה, גם כשהטלפון נעול והאפליקציה סגורה. הכול בחינם: בלי App Store, בלי מנוי מפתחים של אפל ובלי שרת בתשלום.

## איך זה עובד

- **האפליקציה** היא אתר שמוסיפים למסך הבית. מרגע שהיא שם, היא נפתחת כמו אפליקציה רגילה ועובדת גם בלי אינטרנט.
- **השרת** רץ בחינם ב־Cloudflare. הוא שומר עותק של הלו״ז, ובדקה של כל תזכורת שולח התראה לטלפון.
- כל שינוי בלו״ז, כל סימון "ביצעתי" וכל "להזכיר שוב" מתעדכנים בשרת אוטומטית. לכן תזכורת שחוזרת עד שמסמנים שבוצע נעצרת ברגע שמסמנים.

## הקמה (פעם אחת, כרבע שעה)

### 1. פותחים חשבון חינמי ב־Cloudflare
נרשמים ב־[dash.cloudflare.com](https://dash.cloudflare.com/sign-up). לא צריך כרטיס אשראי.

### 2. מחברים את המאגר הזה
1. בתפריט בוחרים **Workers & Pages**, ואז **Create**.
2. בוחרים **Import a repository** ומחברים את חשבון ה־GitHub.
3. בוחרים את המאגר `psychic-fishstick`.
4. בשדה **Root directory** כותבים `luz-yomi`.
5. את שאר השדות משאירים כמו שהם ולוחצים **Deploy**.

אחרי דקה או שתיים מתקבלת כתובת בסגנון `https://psychic-fishstick.<השם-שלך>.workers.dev`. זו הכתובת של האפליקציה.

מעכשיו כל עדכון שנכנס למאגר עולה לאוויר לבד.

### 3. מתקינים באייפון של יהונתן
1. פותחים את הכתובת ב**ספארי** (לא בכרום ולא מתוך וואטסאפ).
2. לוחצים על כפתור השיתוף (ריבוע עם חץ למעלה) ובוחרים **הוספה למסך הבית**.
3. פותחים את האפליקציה **מהאייקון החדש**.
4. נכנסים להגדרות, לוחצים **הפעלת התראות** ומאשרים.
5. לוחצים **שליחת התראת בדיקה**, נועלים את הטלפון ומחכים להתראה.

צריך iOS 16.4 ומעלה. ההתראות עובדות רק כשהאפליקציה נפתחת מהאייקון במסך הבית.

### 4. מעבירים את הנתונים מהגרסה הקודמת
הלו״ז שהיה בקובץ המקורי כבר בפנים. כדי להעביר גם את היומן, הסימונים והרשימות שנשמרו בטלפון:
1. בגרסה הקודמת: **הגדרות ← הורדת קובץ גיבוי**.
2. בגרסה החדשה: **הגדרות ← שחזור מקובץ**, ואז סוגרים ופותחים את האפליקציה.

## כדאי לדעת

- **מצב ריכוז ו"נא לא להפריע"** משתיקים גם את ההתראות האלה. אם התראה לא מגיעה, זה הדבר הראשון לבדוק.
- **הנתונים נשמרים בטלפון.** בשרת נשמר רק מה שצריך כדי לשלוח תזכורות: שמות הפעילויות, השעות והשורה הראשונה של ההערה. כדאי להוריד קובץ גיבוי מדי פעם.
- **ייבוא לו״ז מתמונה** עבד בגרסה הקודמת בעזרת Claude, ולא עובד כאן. ייבוא מקובץ טקסט, וורד, אקסל או PDF ממשיך לעבוד.
- **עלות:** התוכנית החינמית של Cloudflare מאפשרת 100,000 פניות ביום. לו״ז מלא משתמש בכמה מאות לכל היותר.

## למפתחים

```bash
npm install
npm run dev      # הרצה מקומית ב־http://localhost:8787
npm run deploy   # העלאה ידנית ל־Cloudflare
```

- `public/` – האפליקציה (`index.html`), ה־service worker, ה־manifest והאייקונים.
- `src/worker.js` – ה־Worker ו־Durable Object אחד לכל טלפון. הוא שומר את המינוי להתראות ואת הלו״ז, ומעיר את עצמו עם alarm בדקה של כל תזכורת.
- `src/schedule.js` – אותם כללי תזכורות כמו `dueEvents` שבאפליקציה. שינוי בכללים צריך להיכנס לשני המקומות.
- `src/webpush.js` – Web Push (הצפנה לפי RFC 8291 וחתימת VAPID) על WebCrypto בלבד. מפתחות ה־VAPID נוצרים לבד בפעם הראשונה, כך שאין סודות להגדיר.
